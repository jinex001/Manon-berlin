# Brasserie Manon – Website

Statische Website der Brasserie Manon in Berlin. Reines HTML, CSS und JavaScript, ohne Build-Schritt.

## Struktur

```
index.html         Startseite (Über uns, Karte, Öffnungszeiten, Kontakt)
impressum.html     Impressum
datenschutz.html   Datenschutzerklärung
css/style.css      Gestaltung
js/main.js         Sprachumschaltung DE/EN, Jahreszahl
```

## Lokal ansehen

`index.html` im Browser öffnen, oder:

```bash
python3 -m http.server 8000
# dann http://localhost:8000 öffnen
```

## Noch zu erledigen

Alle Stellen mit `[TODO]` bzw. `<!-- TODO -->` müssen mit echten Angaben gefüllt werden:

- [ ] Text „Über uns“
- [ ] Echte Speisekarte mit Preisen
- [ ] Öffnungszeiten
- [ ] Adresse, Telefon, E-Mail
- [ ] Impressum (Pflicht in Deutschland, § 5 DDG)
- [ ] Datenschutzerklärung
- [ ] Fotos
- [ ] Veröffentlichung (z. B. GitHub Pages) und eigene Domain
